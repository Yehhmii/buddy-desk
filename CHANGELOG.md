# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- Voice assistant with wake word, continuous conversation, and an end phrase
- Tasks with notes, priorities, due dates and screenshots
- Alarms and timers, including a Windows wake timer so alarms ring while the PC sleeps
- Daily report, with an offer to read it aloud when you are at the computer
- Screen reading (OCR) and screenshot capture
- Characters: Orb (with custom colour), Buddy, Luna and Rex
- AI providers: Groq, Google Gemini, OpenAI (ChatGPT API) and Anthropic (Claude API), with automatic failover
- Offline voice recognition fallback for people without a cloud speech key
- First-run guide, floating overlay window, system tray, automatic updates
- Windows and macOS builds
